# 『タイトル未定』：軌跡インクスラッシュアクション 企画・実装仕様書
## 1. ゲーム概要 & コアコンセプトタイトル: 未定（仮：Project InkSlash）
ジャンル: 2D/3D見下ろし型 インクスラッシュ・高速アクション視点: トップダウン（見下ろし平行投影 / 正射向カメラ Orthographic または 低FOV Perspective）
コア体験:タイムスロー中にマウスで「インクの軌跡」を描き、離した瞬間に一撃で敵を両断する爽快感。自身が描いた軌跡や敵撃破時に飛び散る「インク」に触れることでゲージを回復し、連続攻撃へ繋げるリソース管理とハイスピード感の両立。
### ゲームの流れ:プレイヤーはステージ内の複数の部屋を探索し、各部屋に配置された敵を撃破しながら進む。
ステージは3つ想定(できればもう少し多く)で、1つのステージに何個か部屋がある感じ。部屋の中に扉がどこかに一つあって次の部屋に進んでいき、ゴールのオブジェクト(どういうものかは未定)に触れたらクリア。
最後のステージはボス。
### プレイヤー
インクを回収は、右クリックしながら線に触れると回収できる。回収できる割合は、書いた線の面積が1だとしたら、回収できる割合は2。回収したところのインクは消える。
### 敵
1: 突進型（プレイヤーに向かって直線的に突っ込んでくる）
2: 高速追尾型（プレイヤーを追尾してくる）
3: 砲撃型（遠距離から弾を撃ってくる）
4: ボス（複数の攻撃パターンを持つ）
5: その他、ステージギミックとしての敵（動く壁やトラップなど）できたらでいい。

## 2. 操作仕様とインクメカニクス
### ① 操作方法と状態遷移操作状態アクション / 挙動詳細WASD通常時プレイヤーキャラの足場調整・移動。※ドラッグ中は入力無効。左クリック長押し (ドラッグ)軌跡描画時タイムスロー発動 ＋ WASD移動ロック ＋ 軌跡（インクライン）の描画。描いた長さに応じてインクゲージを消費。左クリック離す超高速移動時描いたインクの軌跡に沿ってプレイヤーが超高速移動し、軌跡上の敵を斬撃・撃破。
### ② インクシステム (リソース・循環メカニクス)インクゲージ（ライン長上限）:描ける線の長さには最大値（インク上限）が存在する。インク量が 0 になるとそれ以上線を描けない。軌跡のインク化:プレイヤーが引いた線はその場に「インク」として地面に残る（回復されるまで持続）。敵撃破時のインク爆散:敵をスラッシュで撃破した瞬間、その死亡地点を中心にインクが放射状に爆散し、地面に巨大なインク溜まりを生成する。インク回収（ゲージ回復）:プレイヤー（通常移動）が地面の「インク（自ら引いた線、または敵の爆散インク）」に接触すると、インクゲージが即座に回復する。

## 3. 仕様上の制御ルール（確定仕様）
### 1. ドラッグ中の移動制限と時間制御ドラッグ開始時:内部タイムスケール timeScale を 0.1f（スロー）に移行。WASDによる移動ベクトル加算を即座に (0, 0, 0) に固定し、操作を受け付けなくする。ドラッグ終了時:timeScale を 1.0f（通常スピード）に即時復帰。
### 2. 壁（障害物）による描画遮断マウスを動かして次のポイント $P_{next}$ を打つ際、直前のポイント $P_{last}$ から $P_{next}$ へ向けてレイキャスト（Raycast）を実行。ステージの壁（Wall Collder/Mesh）にヒットした場合：ヒット地点（衝突座標）で線の追加をストップし、それ以降のマウスドラッグによる追記を強制遮断する。
### 3. インク消費と線長制限現在描いた全線分の総距離 $L = \sum \vert{}P_{i} - P_{i-1}\vert{}$ を算出。$L \ge \text{残量インク}$ となった時点で、ドラッグを継続していても線描画処理をストップ（ドラッグ終了待ち状態）にする。
#### 4. 自作エンジン向け システムアーキテクチャ & 実装仕様C++ や OpenGL / DirectX / Vulkan 等を用いた自作エンジンでの実装を想定したロジック設計です。
A. スクリーン座標 $\rightarrow$ ワールド座標変換 (Raycast)マウスのスクリーン座標 $(X_{scr}, Y_{scr})$ から、カメラのビュー・プロジェクション逆行列 $(P \cdot V)^{-1}$ を用いてワールド空間のレイ $R(t) = O + t D$ を生成。地面平面（例: $Y = 0$）との交点を計算し、ワールド空間上のマウス指す位置 $P_{mouse}$ を取得。$$\mathbf{P}_{ground} = \mathbf{O} - \left( \frac{\mathbf{O}_y}{\mathbf{D}_y} \right) \mathbf{D}$$
B. 線描画 & 壁・インク制限アルゴリズムvoid OnMouseDrag(Vector3 newWorldPos) {
    if (inkGauge <= 0.0f) return;

    Vector3 lastPos = pathPoints.back();
    Vector3 dir = (newWorldPos - lastPos).Normalized();
    float dist = (newWorldPos - lastPos).Length();

    // 1. レイキャストで壁判定
    RaycastHit hit;
    if (Physics::Raycast(lastPos, dir, dist, Layer::Wall, &hit)) {
        // 壁に当たったらヒット位置まで引いて終了
        pathPoints.push_back(hit.point);
        StopDrawing(); 
        return;
    }

    // 2. インク残量チェック
    if (dist > inkGauge) {
        // 残りインク分だけ伸ばして終了
        Vector3 endPos = lastPos + dir * inkGauge;
        pathPoints.push_back(endPos);
        inkGauge = 0.0f;
        StopDrawing();
        return;
    }

    // 3. ポイント追加とゲージ消費
    pathPoints.push_back(newWorldPos);
    inkGauge -= dist;
}
C. 高速移動と線分衝突判定 (Swept Sphere / Raycast)移動: 離した瞬間、蓄積された pathPoints（プレイヤー現在地 $\rightarrow$ 始点 $\rightarrow$ 中継点 $\rightarrow$ 終点）に沿って毎フレーム Speed * deltaTime 分だけプレイヤーの座標を補間（Lerp / Spline）。攻撃判定: 1フレーム前のプレイヤー位置 $P_{prev}$ から現在位置 $P_{curr}$ へのカプセルまたはスイープ球判定を行い、接触した敵の TakeDamage() を呼び出す。
D. インクのグラフィックスと判定システム (自作エンジン実装)軌跡の描画 (Ribbon Mesh):各 pathPoints から、カメラ視線方向（または地面法線）に対する外積で左右に頂点を押し出し、ポリゴン帯（Ribbon Mesh）を動的に生成して描画。敵爆散インク (Particle & Splat Quad):敵死亡時、地面に円形ポリゴン（またはデカールビルボード）を生成し、インクテクスチャを貼り付ける。インク回収の当たり判定:地面に生成された「インクラインの線分」および「爆散インクの円」をトリガーオブジェクト（またはシンプルな数学的距離判定）として保持。プレイヤーの座標がインク判定内（線分からの距離 $r < \text{Threshold}$）に入った場合、インクを消滅（または減衰）させて inkGauge を回復。

### 6. まとめ（20時間で魅せるポイント）スローと静寂 $\rightarrow$ 一瞬の超高速スラッシュ のメリハリ。敵を切り倒した瞬間に バシューンと弾ける鮮やかなインク。インクの上を滑るように次の攻撃へとループ させる爽快感。グラフィック素材は自作の簡易なシェーダーと基本形状（Cube / Sphere / 動的Mesh）で完結させつつ、インクの鮮烈な色（ネオンカラーやビビッドカラー）で視覚的インパクトを最大化します。
