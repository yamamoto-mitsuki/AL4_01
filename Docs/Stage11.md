## ステージ11 の中身（Level11.scene.json）
1. **追い風**：風なしでは届かない 7.6m の穴（いつも同じ強さの追い風）→ 8.2m の穴（ゆれの大きい追い風。風の筋が速いときに跳ぶ）。
2. **後ろへ吹っ飛ぶ**：緑の円は左上（来た方）へ飛ばし、宙に浮いた緑の壁に張り付く → 壁ジャンプで右へ → 水色の円 → 浮いた岩へ。
3. **円と壁のジグザグ**：左右の緑の壁は 9m 離れていて、壁ジャンプだけでは届かない。真ん中の水色の円を挟んで「円 → 右の壁 → 円 → 左の壁 → 円 → 崖の上」。壁は短く、1 枚の壁だけでは崖の上に届かない。
4. **吹っ飛びから跳び降りる**：緑の円はまっすぐ右へ飛び続ける（End At Path End を外してある）。そのままだとゴールの崖の横にぶつかって落ちる。崖の 2〜5m 手前でジャンプして、吹っ飛びをやめて崖の上へ。
